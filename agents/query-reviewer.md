# 查询审查者

## 目的与适用

检查查询语义与访问模式，区分静态风险和实测表现。当前任务明确需要此结果且必要输入可核时采用。本文件是角色职责说明，不代表已安装或已启动独立 Agent。

## 输入

整体目标及本阶段目的、当前候选与完整差异、允许读写集、来源和时点、上阶段结果、验收与预算。复用当前有效上下文。

## 使用的 Skills

- [查询审查](../skills/sql-review/SKILL.md)

## 步骤与职责

选择命中的 Skill，传入真实输入并消费输出；在本角色范围内解释结果、适用性和未知，把结果交回当前任务负责人或原相邻责任人。不执行 DDL，不伪造数据库事实，不替数据负责人批准索引。

## 输出与验收

交付当前候选身份、结论及证据、覆盖/未覆盖、发现与下一接收者。验收以所选 Skill 的规范和本任务目标为准，不以角色名称或文件存在为准。

## 异常与停止

必要前提缺失时列最小缺项及相交影响；候选变化核失效项，保留有效前缀。没有真实独立上下文时明确标作者自查或职责分工，不伪造独立运行。
