# 最小任务交接空表

可合并到已有对话、计划或任务记录中。简单任务用几句话即可；现有流程已经记录的字段直接引用，不复制总体进度。记录放在使用者授权的项目位置，私有工程事实不提交到本公开仓库。

```text
目标 / 本轮变化：
实际工程 / 当前阶段：
候选身份（版本与未提交差异）：
当前授权 / 允许读写集 / 禁止动作：
Brain 交接的入口 Agent / 实际执行方式：
Agent 选中组织入口、模板及实例位置 / 适用理由：
当前责任人 / 接收者（注明实际执行方式）：
已有输入 / 已完成且仍有效的证据：
下一动作 / 预期产物 / 可观察验收：
未决 / 在途或结果未知的动作：
停止与恢复条件 / 适用累计预算：
```

缺项写未知及其影响，不编造成功或授权。候选变化后标明失效范围；需要独立审查时，保留真实上下文与同候选回执，作者自查不能替代。
