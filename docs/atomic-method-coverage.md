# 原子方法覆盖盘点

## 盘点范围与判断

初次盘点于 2026-11-04 检查本地方法入口的 74 份顶层 Markdown 目的及目录元信息，并定向展开文档目的、原子属性、加载、执行接续、上下文拆解、文档保留与诊断反证正文。2026-11-10 按同一层级刷新为 76 份，新增两份执行端协作入口。本轮定向展开 SQL 审计、八类查询风险及其 Skill，其余候选按已读目的/标题记录读取深度。数量是入口文件数，含导航、模板与专项材料。
