**目的**：说明本轮公开原子盘点的覆盖、补齐、缺口与排除范围，使后续补充有明确依据。

**适用于**：维护本 Java/Spring 框架方法目录的使用者；本表是限定范围的作者盘点，不是全量迁移或独立运行验收。

# 原子方法覆盖盘点

## 盘点范围与判断

本轮以本地方法入口的 74 份顶层 Markdown 目的及目录元信息盘点候选，与当前公开 Standards/Skills 对照，并定向展开文档目的、原子属性、加载、执行接续、上下文拆解、文档保留与诊断反证等相关正文。74 是入口文件数，包含导航、模板与专项材料，不是 74 个独立原子。

没有遍历所有子目录、企业适配、历史证据、工具实现和业务资料。下表按任务方法归组，不把文件同名当完整覆盖；未展开的候选仅作后续定位，不能声明正文已审。私人路径、公司专项坐标、生产规则、运行样本及本机固定授权不进入公开内容。
