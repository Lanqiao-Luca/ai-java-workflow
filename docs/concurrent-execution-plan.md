# 执行实例隔离与Graph并发执行文档

目的：为每个执行实例分配可核的工作区与实际权限边界，组织Graph并发调度多个已声明Workflow实例，最后在单一目标串行集成并重新验证。本文件先于实现及案例目标文件写入保存；计划不等于机制已实现或沙箱已验证。

## 方法归属与实现

- Standards：维护工作区、沙箱权限、并发、集成及停止判据。
- Skill：适配准备、能力探测、资源分配、执行、证据与安全回收。
- Agent：在任务范围内选择隔离并承担结果与交接责任；方法文档不自动增加权限。
- Workflow：组织单实例阶段及首尾资源管理；Graph按实际依赖直接调度已声明Workflow实例，不为空层级创建Loop。
- tools/execution：共享执行机制的新编写实现，使用Python标准库；不是新增方法层，也不复制私有Tools。

## 实例与权限合同

| 对象 | 必须固定与验证的内容 |
| --- | --- |
| 实例身份 | 唯一run_id、父子关系、Workflow身份、冻结base_commit、允许动作/写集、预算及执行候选 |
| 工作区 | 独立分支及真实Git worktree；输入dirty默认拒绝，需快照时必须明确形成获准快照，不隐式带入其他改动 |
| 本地sandbox | 明确backend、实际策略、可读/可写范围、只读工具路径及负例探测；目录或临时配置不能冒充完整沙箱 |
| 子进程环境 | 独立HOME/TMP与必要配置，环境变量白名单，不向子进程提供宿主凭据或共享Git管理目录；Git管理动作由宿主执行 |
| 状态与证据 | 同一实例单状态写者；绑定来源/候选/动作和结果，过程证据可追溯；未知结果不能改名成功 |
| 资源回收 | 核活跃进程、干净状态、未决动作和必要证据；非clean、活跃或未知资源保留并交恢复条件，禁止force清理 |

## 并发、依赖与集成

1. Graph先检查DAG、节点身份、依赖、写集及目标；父子Workflow共享全Graph的max_parallel额度，不能各自重置限额。
2. 只有必要依赖成功且资源/预算有效才调度节点。无关安全分支可继续；同目标写入和共享状态由唯一责任者控制。
3. 每个run_id分配独立分支、worktree、沙箱策略和配置；执行前验证实际权限，失败即拒绝，不降级成裸subprocess仍称沙箱。
4. 每次执行记录真实开始/结束、状态及证据；超时/取消终止整个进程组，核结果再决定恢复，不遗留未登记子进程。
5. 同目标ref串行集成，先核候选、工作区与依赖状态，遇冲突阻断相交集成，保留双方有效内容；禁止用force覆盖。
6. 集成后对最终候选重新验证，不能以两个分支各自通过代替合并结果通过。恢复复用有效前缀，不重复已受理副作用。

## 平台与能力探测

宿主先探测真实可用backend。本轮可尝试Darwin的sandbox-exec/Seatbelt；它是deprecated工具，本轮实现若通过仅能声明已测macOS实验性backend，不承诺通用跨平台或恶意代码完全防护。

策略deny-by-default，读写限当前实例及具名只读工具范围，默认拒网络。使用独立构造的仓库外canary测试拒读/拒写，不读取真实凭据；网络负例只验证拒绝，不传源资料。后台、系统/平台配置不改，不使用系统安装器。

能力不可用、策略不生效或backend不支持时fail closed，实际运行保持NOT_RUN/blocked等真实状态；允许完成不依赖该能力的独立工作，不伪造强隔离证据。

## 完整案例与验收

案例使用独立虚构Git种子repo：两个并发Java小模块Workflow和一个集成Workflow，共享冻结base_commit，分别有run_id、分支、worktree、sandbox与证据；Graph组织依赖及统一额度，集成只有一个目标ref。真实worktree及工具链均放临时运行目录/仓库外，不在本项目main创建业务分支运行环境。

| 验证项 | 所需真实证据 |
| --- | --- |
| 分支与工作区 | 不同run_id对应独立真实分支/worktree、同一冻结基线 |
| sandbox负例 | 自造canary拒读/拒写、默认拒网络、只读工具不能写；不以文字声明代权限测试 |
| 并发与依赖 | 全Graph最大并发、依赖顺序与单状态写入记录，可回实际事件 |
| Java行为 | 使用任务临时JDK17真实编译/测试并保实际返回；缺工具明确未运行 |
| 取消/超时/恢复 | 进程组停止、真实剩余状态和最早恢复点，不盲重发 |
| 冲突与脏资源 | 冲突阻断、非clean/活跃worktree保留，拒绝force回收 |
| 集成 | 同目标串行操作、最终候选身份及合并后真实验证 |

案例不是生产服务、真实业务日志或原生LLM Agent自动运行。公共回执使用虚构身份及可移植路径，原始本机日志、绝对路径、工具包、缓存和运行产物留任务临时目录。
