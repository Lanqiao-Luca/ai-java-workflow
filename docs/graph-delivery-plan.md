# 通用目标 Graph 小步交付计划

目标：在现有 Java/Spring、构建与原生 Graph 之外，为多个目标提供依赖、分支隔离、证据门禁及显式收口，并接入已交付的巡检和缺陷 Loop。保留旧 Graph 的各自后端与历史验证范围，不替换它们或把旧实跑签成新能力。

## 顺序与验收

| 步骤 | 独立目的 | 提交前验证 |
| --- | --- | --- |
| G0 | 保存 Loop 状态/待办及本计划 | 文档引用、公开清单与既有身份检查 |
| G1 | 目标图声明与准入合同 | 唯一节点/目标、必需依赖、无环、写集冲突、显式 closure、拒绝无契约的循环 |
| G2 | 有限并发调度与安全检查点 | 失败只阻断后代、独立分支继续、先持久化再派工、总预算、锁与安全前缀续跑、在途 UNKNOWN 不重放 |
| G3 | 候选绑定 Gate 与最终收口 | reviewer/候选/证据身份、拒绝旧证据或空 PASS、required 不被 SKIPPED 替代、closure 节点核所有原目标 |
| G4 | 巡检/缺陷 Loop 接线与虚构图 | 实际调用已交付 Loop；局部 PARTIAL 不洗成全图成功、独立工作仍完成、全部目标满足才收口；可运行案例及负例进入 CI |

每个小步先完成实现、相应测试、八项仓库检查、文档/公开内容核对，再由项目专用提交职责单独提交推送。对应 SHA 的五个 CI 任务全部通过后才进入下一步。失败只修相交内容，不用其他版本绿灯替代，不积压整轮改动一次提交。

## 本批边界

通用 Graph 负责多个目标、依赖、并发与最终完成；Loop 负责单目标有限重复，Workflow/执行适配器负责实际职责和证据。Graph 不把某个 Loop 的 DONE、CONVERGED 或 COMPLETE 不经合同核对统一改成成功，不为简单任务强造图。

仅采用通用方法、公开基线和独立虚构数据重新编写。组织专属业务图、原始运行/审核、内部坐标、私人路径、旧平台接口与退役协议不进入公开内容。文档治理及目的治理的专用图待相应 Loop/Workflow 适配完整后另行安排，不用新通用引擎宣称它们已经迁入。

本批执行为显式前台、受信任回调与私有检查点；不提供新的系统沙箱，不创建后台调度，不自动连接真实服务、提交业务代码或部署。新模型链、生产适配、跨协议转换及恶意多租户隔离分别保留未验。
