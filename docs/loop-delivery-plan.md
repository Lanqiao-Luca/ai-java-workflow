# Loop 小步交付计划

目标：补齐发现闭环与证据失效，新增只读巡检收敛，再核缺陷整体交付。公开内容独立编写，案例全部虚构；不复制私人运行记录、业务实现、平台配置或历史默认参数。

| 顺序 | 独立交付目的 | 本步验收 |
| --- | --- | --- |
| A | 发现账本与证据失效原语 | 稳定发现 ID、修复不等于关闭、三个独立复核、候选/需求/规则变化重开；纯数据测试进入 CI |
| B | 接入原生恢复控制器 | 原失败保留、作者逐项修复、独立阶段明确复核原 ID、未关闭阻断交付；真实私有 worktree 的受控回归 |
| C | 巡检证据收敛 | 虚构日志/接口/构建报告，补证、部分不可得、无增益和预算停止，原范围缺口保留为 PARTIAL |
| D | 缺陷整体交付门禁 | 测试通过仍需所有原验收、发现关闭、实例/副作用及交接义务；虚构案例与负例 |

每步完成实现、相应测试、八项仓库检查和便携回归，再由项目指定提交职责单独提交推送，读取同 SHA 的远程 CI。当前步 CI 未通过前不开始下一步；失败只修本步相交内容，不以旧绿灯代替新版本结果。每步明确实际运行、模拟输入及未验证部分。

本计划不授予生产、远程业务调用、部署或平台后台调度权限。原生模型真实复跑与离线控制验证分开；方法文件不等于运行能力。
