## 实际跑通的链路

[原生Graph](../graphs/native-java-spring.md)组织六个真实原生上下文：需求→实现→独立验证→代码/语义/文档审查与原则审查→交付。两项审查从同一冻结base派发到独立worktree，调用区间重叠；不是模型服务内部硬件调度的并发保证。代码审查节点在一个上下文消费三项职责，不虚增为三个独立进程。

父会话只允许原生派工、等待和核原生状态。适配器根据本次会话身份精确读取对应原生工具调用与完成对，不接受父会话自称成功。全新实例内生成原生角色配置，不修改全局注册；缺角色、协议不兼容、失败或UNKNOWN不降级为角色扮演。

[完整案例](../examples/native-spring-workflow/README.md)的seed没有生产Java。实现者实际生成三个Spring类和七项作者测试，验证者新增五项独立测试；另有宿主预先独立编写的十三项固定合同测试。宿主预热公开依赖时先执行20项；原生离线验证及宿主同候选复验各执行最终25项，退出0、0失败/错误/跳过。重复执行不累加成50项不同业务测试。

最终候选为`2986559d3612bcca8fa0d4c63bd6c1c70890856c1abe10f71d1773dc73dededf`。验证、审查、交付文档身份、完整POM/src映射和宿主回执一致；模型的结构化完成回复不能替代真实字节和构建验收。

## 实际问题与处理

- 首个实例的默认inline Mockito在原生工具沙箱内无法JVM自附加，27项测试均在准备阶段报错，业务断言未运行，下游未启动。确认子Agent完成失败后，任务负责人补公开subclass MockMaker测试SPI，再显式创建新实例重新生成并验证；没有弱化断言、放宽沙箱或沿用旧候选绿灯。失败原件保留私有，引擎不宣称自动修复或未知动作重放。
- 独立复核发现额外父工具调用可能被忽略、路径别名可在拒绝前写入、审查文档可能标旧候选等问题，均已修复并增加定向回归。只处理实际发现，没有开启长期额外治理系统。
- 公开导出复核发现两份原生报告含本机目录。原件排除，由发布整理职责逐段核对后独立编写公开实现说明与审查摘要，明确不是原生原始字节；原始/公开SHA分别声明，原始路径及来源映射留在私有审计。其他Markdown引用可逆迁移，Java/POM/测试/验证JSON保持原字节，不能用摘要豁免源码身份。

## 检查结果与覆盖

54项本地协议/门禁测试通过：原生协议15、Graph门禁17、构建器受控测试8、公开案例正例/变异14。mock角色及模拟Maven/XML只用于门禁，不算原生模型或Spring功能实跑。七个被动检查入口检查清单、引用、类型、源/结果身份和已记录结果一致性，不重新调用模型或构建。

独立候选复核读取新案例全部29文件、构建器、原生案例检查器和旧五类分派增量，未发现新阻塞。公开前逐项检查允许写集；候选检查覆盖隐藏路径、链接与额外文件。原始会话、运行配置、工具路径、失败原件、缓存、target、JAR和Git管理目录不进入候选。未安装的密钥扫描工具没有被记成已运行；程序检查结合真实来源和内容审阅，不把关键词零命中当公开许可。

所有来源为已公开基线及独立虚构材料，本轮没有读取或修改原私有框架。普通推送后独立读回目标ref、完整树及相应文件字节；没有强推、历史重写、Release、CI、部署或账户/仓库展示变更。

## 后续发现的宿主登记边界

最初把“实例内角色配置”与“宿主无全局配置副作用”混为一谈，后者不准确。收尾检查确认：Codex 0.166 CLI、App Server thread/start都会自动保存新执行目录项目信任；瞬时trust覆盖、standalone和省略覆盖均未阻止。外围只读保护会阻断内层工具沙箱，不能靠放宽权限解决；也没有复用无关的已受信任项目。

首次发现的自动新增项已按精确来源移除，使用者原config恢复到任务前完整字节SHA，原有值和文件权限保持。没有把先前副作用追记成当时已有授权。用户随后明确允许本任务临时登记、完成后还原，才继续收尾发布；本次临时登记将在所有相关原生调用结束后精确还原并核验，回执留在仓库外。本次最终还原当前尚未执行。后续任务仍需自己的项目登记许可；要求全局零写入时，当前后端不能运行。真实六阶段/25测试仍是已发生的结果，但不能被解读为零平台配置副作用的验证。

## 支持与未验边界

仅macOS arm64、Codex CLI 0.166.0-alpha.5.1、JDK17、Maven3.9.11、Spring Boot3.5.16实跑。Linux原生链、原生Gradle链、任意现有公司工程、Docker内模型调度、自动整改/续跑和恶意多租户完整隔离没有在本轮实现或验证；旧Docker案例和历史能力保持原义。

本例使用真实Spring测试上下文和MockMvc，不启动HTTP监听、不连接数据库或生产身份、不部署。配置类不等于可执行Boot JAR，原生工具沙箱不等于旧Docker内核探测。本例未使用/验证final或static mocking，其他项目不能直接照搬测试SPI。日常运行不会自动获得GitHub发布许可，提交阶段须按当前项目专门角色与明确授权执行。

在已列明范围和检查方法下，候选中未发现未处理的问题；未检查或无法确认的内容已排除。
