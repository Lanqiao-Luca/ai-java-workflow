**目的**：保存当前公开方法修改前的字节，使历史运行回执继续核对当时真正消费的版本。

**适用于**：历史 Graph、构建和原生案例的身份核验；本目录不参与当前任务执行或提供新版本运行证明。

# 公开方法历史原件

[sources.json](sources.json)登记逻辑来源、旧 SHA 与内容对象，`.txt` 对象保持原始公开字节。原件来自本轮修改前的已公开提交，不含私人方法文件。

[历史来源工具](../../tools/public_history.py)固定清单摘要并校验对象字节，供旧案例检查器使用；当前运行器仍消费现行定义。新增规则和声明不倒填到旧回执，历史回执的候选、运行数据、时间和产物未改。

原生六阶段更早的四份文档版本继续由[原生来源清单](../native-baseline/catalog-sources.json)定位；清单只更新保全位置，不改变原 SHA 与完整来源集合。
