# 模拟确认记录

这是案例作者独立构造的对话条件，不是实际用户/业务方的批准。

| 问题 | 独立虚构的已决口径 | 对实现的影响 |
| --- | --- | --- |
| 修改粒度 | 单个书签；替换整个标签列表 | 不做跨书签批量或追加操作 |
| 空列表 | 允许，表示清空 | 空列表不等于字段缺失 |
| 缺失/null | 拒绝 | 不默认为清空 |
| 单标签处理 | trim后非空；区分大小写 | 空白拒绝，保留内部空格 |
| 重复 | 规范化后按首次出现去重，保留顺序 | 同一个请求有确定结果 |
| 权限 | 仅所有者可改 | 不增加公开协作者写权 |
| 并发 | 不在本次已决范围 | 实施前须从工程确认已有并发保护，不能覆盖它 |

是否允许多个所有者共享标签库：未决定，明确不在当前范围。
