# 需求负责人输出：已决范围与验收

以下已决口径为作者独立构造的案例条件，未把未知事实推成真实公司规则。

- 单个书签，PUT /bookmarks/{id}/tags；全量替换，不做跨书签批量或追加。
- expectedVersion必填；标签列表null/缺失拒绝，空列表允许清空。
- 单个标签null或trim后空：拒绝整次请求。按Java String.trim语义处理，保留内部空格；区分大小写，规范化后首次出现去重并保序。
- 所有者合法、版本匹配后才检查标签；不存在404，非所有者403，缺版本/无效标签400，版本冲突409。JSON解析错误属于HTTP输入层，不纳入业务错误优先级。
- 成功且内容改变才增版本一次、记审计一次；同一规范化结果不写入。保留owner/title/savedSequence。过期重试不能自动换版本放行。

| 验收 | 可观察输入/条件 | 预期与用例 |
| --- | --- | --- |
| A1 | `[" read ","read","Read"]`，owner/版本有效 | 存储为read、Read且保序；normalizeDeduplicateAndPersist |
| A2 | []或null列表 | 前者清空，后者拒绝且完整状态不变 |
| A3 | 有效标签混入空白或null元素 | 整次拒绝，不悄悄丢弃、部分写入或审计 |
| A4 | 非owner、过期/缺版本、不存在 | 对应错误；拒绝保持状态和审计 |
| A5 | 同规范化结果；成功后当前/旧版本重试 | 无变更不增计数；过期版本仍拒绝 |
| A6 | 每次真实改变 | 版本+1、审计+1，owner/title/收藏序号保持 |
| A7 | Spring注入与请求链 | 真上下文、JSON绑定、Controller→Service→错误映射；不由Mock替代 |

未决/范围外：真实认证、数据库事务/持久化、分布式并发、生产配额、标签库、搜索和部署。没有实际SQL，因此查询Agent不触发；不是该职责或数据库性能已通过。
