# W50文档可消费性检查

核使用者可取得：需求与假设、源码/差异、运行环境、精确命令、红绿判断、已做/未做、失败停止和接续责任。当前README提供run.py入口，run不把构建产物写回不可变案例；缺环境返回NOT_RUN。

运行器只输出脱离本机路径的结果摘要，公开回执仅列版本、源码SHA、用例及真实退出结果，原始机器构建日志不入库。身份清单覆盖全部案例文件但不含自身；运行回执的源码ID不包含自身，避免循环哈希。

外部官方资料在sources.json登记，可读性/链接不代依赖安全或运行验收。文档和代码自查不等于真实分离审查；independent.md记录实际范围。发布结果另在仓库docs，不向案例内倒填自身提交SHA。
