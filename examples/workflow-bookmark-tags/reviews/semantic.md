# W42语义核验：作者映射

从需求追实现：A1去重/保序/存储，A2清空与null，A3整次拒绝，A4身份与版本，A5无变更/重试，A6保持及审计，A7Spring装配，均在同候选代码和13项测试中有对应。
从实现反查需求：没有增加跨书签批量、标签共享、自动重试或SQL；GET仅供内存状态观察的服务方法，不增加HTTP读接口。
反例：混入无效元素必须整次拒绝；非owner+null必须先拒绝owner；相同规范化结果不能增版本；成功后旧版本必须冲突。v1违反A3，v2同测试复验。

未把trim当全部Unicode空白规范化；未宣称真实身份认证或分布式幂等。当前无未决业务语义被默认放行；范围外事项仍未验。独立复核见independent.md。
