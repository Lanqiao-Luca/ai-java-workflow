**目的**：把已确认需求落实为最小代码候选，交行为保持映射、实际验证和未决。

**适用于**：已确认需求与明确写集内的实现、修复或受控重构；关键契约缺失时只停依赖实现。

# 代码实现

## 适用条件与输入

适用：目标和允许写集已明确，能够定位当前代码。输入为需求/验收、当前代码与未提交差异、允许范围、工程事实及已有验证。已知信息复用；缺少关键契约只停相交实现。

## 输入怎样变成输出

| 步骤 | 实际消费 | 输出与进入下一步的条件 |
| --- | --- | --- |
| 固定基线 | 当前代码、工作树与允许写集交基线规范 | 文件/版本身份、既有改动和禁止动作清楚；否则先补定位 |
| 追现有行为 | 相关入口、方法、数据及副作用交行为保留规范 | 已有能力取舍、调用者和保持项有源码依据 |
| 检查重复规则 | 同语义消费者交共享规则规范 | 真有多个消费者才查共享接线；没有则给不适用依据，不造公共层 |
| 最小修改 | 已决变化与上述结果 | 在允许文件落差异，不改无关语义、类型或技术栈 |
| 作者自查 | 当前候选与验收交验证规范 | 实际用例、命令、失败/未运行和覆盖逐项对应；自查不是独立验收 |
| 交回角色 | 差异、映射及证据 | 同候选身份、限制和恢复点，交接收角色作责任判断 |

Skill 负责参数适配与真实结果，不自行扩权、委派角色或建立上层循环。命中 Java/Spring 时由角色选择专项 Skill，不用这里的伪命令代工程工具链。

## 输出与职责

交回实现候选、行为映射、真实验证、未验项和下一动作。实现者对目标、范围和交接负责；不把原始历史样本当本次输入，不以测试源码存在当测试成功。

## 验收

每项已决变化有实现落点，每项必要保持行为有接线与验证依据；完成声明只覆盖真实证据。缺运行环境时可交待验候选；不能签功能通过或需要独立上下文的审查。

## 异常与停止

基线变化先核失效项；写集冲突暂停相交修改。需求反转回有权决定者，失败保留可复现前置，环境不足交具体接续命令。未知副作用先查原状态，不自动重放或安装工具。
