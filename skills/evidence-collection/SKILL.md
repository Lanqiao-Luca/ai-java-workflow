**目的**：把采集目标适配成来源前检、事实保真、覆盖判断与安全停止，交可复核证据包。

**适用于**：责任 Agent 已接收明确命题、来源边界、质量模式及预算的采集或给定材料核查。

# 证据采集

## 方法与输入

消费[EC01–EC04](../../standards/evidence-collection.md)，按需采用[按需加载](../../standards/progressive-loading.md)和[恢复](../../standards/recovery.md)。来源对象与实际许可由当前任务交入，模式字段或工具可用不能自行授予权限。

## 适配

1. 核命题、实际来源/版本/条件和允许读集，优先复用仍有效的原件；没有明确来源合同不猜调用参数。
2. 用当前支持的接口取得材料，记录原件、位置、查询身份与质量；解析不覆盖原件，失败/未执行/未知不填零。
3. 对显式提供的页观察，可用[覆盖判定工具](../../tools/evidence_coverage.py)核同源/同查询/同快照、连续游标、停止、正控制与模式。工具不发请求、不认证来源或读取权限，也不提供批量执行客户端。
4. 返回事实与范围、sample/complete、缺口、原断点和下一责任。具体采集仍依赖实际来源适配器，不以声明判定通过代真实来源验收。

## 异常

拒权、截断或未知停止相交新源，原结果先查状态后续；不擅加轮次、扩窗口、缩小原目标或修改业务。保存文档沿当前文档维护职责。
