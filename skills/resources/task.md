**目的**：帮助记录任务目标、候选、写集、保持项与可观察验收。

**适用于**：需求准入和任务交接；填写内容必须有实际来源，未知不补造。

# 任务与验收空表

用途：保留足够的当前上下文，不要求为小任务重复建账。填写后由需求负责人确认可实施范围。

| 字段 | 填写内容 |
| --- | --- |
| 整体目标与来源 | 待填 |
| 候选身份与完整差异 | 待填 |
| 允许根、写集与禁止动作 | 待填 |
| 改变行为、保持行为 | 待填 |
| 现有调用链、依赖与未知 | 待填 |
| 对象、输入、前置、预期及拒绝条件 | 待填 |
| 必要验证、环境与清理 | 待填 |
| 未决、责任、停止及恢复条件 | 待填 |

验收：关键范围可核；不知道的项目填未知，不为填表造事实。返回：[Skills](../README.md)。
