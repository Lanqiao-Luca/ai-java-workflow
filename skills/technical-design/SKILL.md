**目的**：把设计输入和原子方法适配成可由实施者消费的新方案。

**适用于**：已确认目标、工程读集和产出写集的设计编制或局部修订。

# 技术方案编制

## 输入与方法来源

接收责任 Agent 给出的当前目标、来源/候选、读写集、预算、验收及恢复点。方法单源：

- [design-inputs](../../standards/design-inputs.md)
- [technical-design](../../standards/technical-design.md)
- [behavior-preservation](../../standards/behavior-preservation.md)

## 适配步骤

1. 消费输入原子，固定已决、假设与来源水位；没有源码不编造现有实现，没有产品 PRD 时用真实技改目标。
2. 消费方案原子，形成需求-设计-验收映射和当前能力/保持项，再写选择依据、契约、数据与异常、落点依赖及恢复。
3. 使用[设计模板](templates/design.md)组织所需内容，不为凑章节删要求或造事实。候选文件生成后记录版本/SHA、关键假设与作者来源，交角色安排专业复核。
4. 收到当前发现后只修相交内容，返回新身份与失效审验；没有真实测试或渲染时明确未运行。

## 输出与边界

返回当前候选、方法覆盖、来源/假设、实际检查与未验、阻塞及下一责任。文档保存沿现有文档维护职责；Skill 不自行选择或启动上层流程。角色负责结论、授权和交接，工具不签语义或业务通过。
