# 冻结输入、发现与定向复核

目的：将研发经验表达为可复用、可验证的方法。

## 适用条件

形成可审代码差异后。

## 输入

需求及规则、完整候选身份、作者、差异、验证和允许读范围。

## 操作步骤

先固定输入与审查范围，核差异及实际调用者。对发现写明位置、触发、预期、实际、原始证据、影响、反例及可执行关闭标准。修复由有权作者实施，审查者核修订后的失效项及直接依赖，保留未受影响的有效结果。版本变化不能抹掉旧发现。

## 输出

审查结论、发现清单、处置与剩余缺证。

## 角色职责

作者负责修复，审查者负责所审范围的判断；自查与独立上下文分别标记。

## 验收方法

阻断发现按当前证据复核；作者回复已修不代替需要的审查结果；没有把普通审查等同外部独立审核。

## 异常与停止

范围或候选漂移重新固定相交输入；缺证先限定结论，不扩大读取无关项目。

方法文档本身不提供执行权限，也不证明实际运行。返回：[Standards](README.md)。
