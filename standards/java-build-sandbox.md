# 可信Java构建树的沙箱合同

目的：在独立实例内运行真实构建，区分默认禁止fork与显式可信构建模式，不用并发目录冒充隔离。

## 适用条件

已审阅、获授权的本机Java/Spring源码和构建插件需要子JVM；当前仅macOS实验Seatbelt。源码及工具须可信，不用于恶意插件或敌对多租户。

## 输入

冻结提交、Graph/Workflow合同、唯一run_id、明确JDK/Maven/Gradle工具根、显式预热的公开依赖缓存、逻辑写集、作业额度与截止时间。

## 操作步骤

1. 默认严格模式保持禁止fork；可信构建必须使用独立入口和backend，不能静默降级或混用旧探测语义。
2. 依赖准备使用空HOME与空配置，仅公开仓库，独立输出。缓存逐文件SHA封存；执行前及复制前核身份，禁止个人settings/init脚本、链接和来源不明缓存。字节封存证明身份，不能单独证明权属或无凭证。
3. Graph执行使用各实例独立HOME/TMP、Maven仓库、Gradle用户及项目缓存、构建输出；offline模式缺依赖即失败。工具只读，源码提升仅允许声明源码文件。全局用户配置和注入环境不继承。
4. 子进程继承Seatbelt文件/Git/外网限制。Gradle Worker需要loopback；当前模式允许本机回环通信，无法隔离同机其他服务，不能标称只允许自身IPC或全网拒绝。案例只连接自造服务，不请求任何业务服务。
5. 宿主观察进程PID/父子/组/启动元数据，不读取其他进程的命令行或环境。前台构建等待子任务，默认拒绝已观察到的脱离会话；Gradle一次性Daemon须显式opt-in，仅允许已观察且持续跟踪的继承沙箱后代，客户端结束后最多3秒等待其自行停止，仍残留即终止并拒绝提升；超时/取消停止本次观察到的树。观察失败或未确认停止保持active并隔离池，禁止自动释放/重放或清理未知资源。
6. 禁复用长期Daemon，限制Maven forkCount和Gradle workers；Graph槽位计作业，包含其正常子树，不等于所有JVM总数硬限制。核退出码、精确成功行、真实JUnit报告、候选字节/HEAD/index/写集；合入精确提交后重跑集成验收。

## 输出

工具版本、来源/缓存/合同身份、真实JUnit统计、独立测试JVM事实、实例与依赖结果、观察到的进程停止、回收状态和未验边界；原始日志默认私有。

## 角色职责

构建执行者确保调用合同与实际配置一致；宿主管理实例/观察/共享额度和Git提升。角色文档不代表原生AI进程已经注册。

## 验收方法

真实Maven及Gradle执行、子JVM与继承限制负例、独立缓存、退出后无已观察残留、并发/额度/依赖、合并后Spring测试与失败不提升。缺依赖、跳过测试、空报告或仅退出0均不能记通过。

## 异常与停止

不支持平台/后端不裸跑；未知占用隔离。轮询树观察不能保证抓住瞬间双重fork并重归属的恶意进程，PID起始时间检查也不是pidfd原子句柄；宿主SIGKILL后无自动全后代回收保证。该模式不能用于敌对代码，不能等同容器PID命名空间/cgroup。仅提供CPU/单文件及作业槽位限制，没有总RAM/总磁盘硬配额。
