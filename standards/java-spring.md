**目的**：核 Java/Spring 改动的装配、依赖和实际工程行为，定位需要验证的影响。

**适用于**：供当前方法的责任 Agent、作者与审查者使用；目标工程使用 Java 或 Spring 时。

# Java/Spring 实现检查

## 适用条件

目标工程使用 Java 或 Spring 时。

## 输入

实际构建文件、CI、源码、依赖与运行配置。

## 操作步骤

从当前工程确认语言与框架约束，沿用其有效约定。核注入、事务边界、异常语义、资源关闭、空值和集合行为；修改共享状态时检查线程安全。配置、Bean、profile 或打包发生变化时，用真实容器装配测试验证，不能用 Mock 注入替代。数据库和事件调用核当前事务与重复处理策略。文档中的注解偏好不作为所有项目统一禁令。

## 输出

本工程适用规则、改动风险与验证证据。

## 角色职责

实现者判断适用性，验证者核实际行为和装配。

## 验收方法

编译与测试使用工程实际工具链；核心依赖缺失的行为符合当前契约；没有为消除启动错误随意改为可选依赖。

## 异常与停止

缺环境或依赖时记录未验证，不强制升级版本、下载工具或接入服务；不能把通用清单当真实工程已通过。

方法文档本身不提供执行权限，也不证明实际运行。返回：[Standards](README.md)。
