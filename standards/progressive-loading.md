**目的**：以任务和读取条件组织入口与来源，减少无关加载并保留必要合同。

**适用于**：供当前方法的责任 Agent、作者与审查者使用；定位、组织或维护框架知识，且需要控制无关读取与保持来源可追溯时。

# 按需加载与文档导航

## 适用条件

定位、组织或维护框架知识，且需要控制无关读取与保持来源可追溯时。

## 输入

任务目标、当前项目与允许读集、已有效加载的来源、当前入口与缺失信息。

## 操作步骤

项目已知时从适用入口定位当前正文，再取必要证据；先看任务条件、标题和章节，读到足够行动即可。明确要求全文读取的合同仍完整消费，不能用摘要绕过；工具返回截断时只补缺失范围。

README 保职责、读取条件与指针，规则正文保持单源。Skill 由责任 Agent 选择，不因链接存在就全量加载。已读且未变的来源从当前上下文复用，收到变化通知或确缺上下文时才定向刷新。

移动前核真实消费者与入链出链；内部链接按最终位置计算，子文档给返回入口。历史来源保原身份，失效来源明确缺证，不用不可达链接冒充已接入能力。

## 输出

实际读取范围、所需来源、有效复用与缺项，或有依据的导航变更及验证结果。

## 角色职责

作者维护入口与单源关系，当前执行 Agent 判断所需材料；工具只提供定位和读取。

## 验收方法

下一消费者可以取得必要信息而无需全量阅读无关分支；实际加载效果与静态引用检查分别报告。没有可比测量不宣称 token 或速度收益。

## 异常与停止

关键来源缺失或预算不足时只停依赖动作，保最小缺段及恢复点；不扩大扫描私有知识库，不因整理而搬改受保护原件。
