**目的**：组织文档定界、维护、自查、审验与交付，保持同候选和原件保护。

**适用于**：已确认写集与读者/来源的本地文档任务；真实分离审验缺失时明确待验。

# 文档维护与审验 Workflow

## 输入与组织

[任务协调者](../agents/task-coordinator.md)或入口文档 Agent 接收目标、候选、允许写集、读者/来源与验收，沿当前任务实例记录计划与状态。无需多目标 Graph 或重复 Loop 时直接执行本单轮，不强建上层。

| 阶段 | 责任 Agent | 产物与继续条件 | 失败返回 |
| --- | --- | --- | --- |
| 定界 | 任务协调者或入口文档维护者 | 写集、现有改动、原件身份、验收与预算 | 缺项只停相交动作 |
| 维护 | [文档维护者](../agents/document-maintainer.md) | 同候选正文、目的与适用语义判断、属性与保全证据 | 目的冲突回任务决定，内容缺口回作者 |
| 验证 | 文档维护者作者自查 | 当前字段、引用、清单和真实检查结果 | 结构或来源问题回维护 |
| 审验 | [文档审查者](../agents/document-reviewer.md) | 同候选内容发现与关闭标准，真实分离上下文才称独立 | 修订回作者，复验失效项 |
| 交付 | [交付规划者](../agents/delivery-planner.md) | 实际完成、未验、原件定位和接续 | 必要缺证不报整体完成 |

## 完成与边界

没有真实分离审验回执时报告作者自查及待验，不以同一助手切换角色名作独立验收。授权内确需重复审查整改时由 Brain 选择适用 Loop，原协调者与阶段职责沿实例接续并保累计预算；本 Workflow 不自动委派、联网、清理或发布。
