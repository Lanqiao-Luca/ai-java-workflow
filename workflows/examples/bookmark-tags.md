# 书签标签：Workflow 执行文件

性质：独立虚构的已填计划。状态：NOT_RUN；无模型、Java、独立审查新回执。

| 项目 | 实例定义 |
| --- | --- |
| run_id / 目标 | demo-workflow-tags；替换标签时保留未指定字段 |
| 模板 / 方法 | [计划模板](../templates/execution-plan.md) / [研发 Workflow](../java-spring-development.md) |
| 入口责任 | [任务协调者](../../agents/task-coordinator.md)接受 Brain 任务后调取本层 |
| 工程与候选 | 使用者独立的虚构书签工程；实际路径与完整差异尚待绑定 |
| 授权与写集 | 仅本地标签服务及相关测试；无提交、推送或部署许可 |
| 预算 | 仅一轮；执行前由使用者确认实际时间预算 |
| 父层 / 总体状态 | 无；本实例承担总体状态 |

| 阶段 | 责任 | 输入与预期输出 |
| --- | --- | --- |
| 需求 | 需求负责人 | 明确空列表、空白项及保持字段的语义 |
| 实现 | 实现者 | 以确认契约产出最小服务与测试差异 |
| 验证 | 验证者 | 记录当前候选、实际命令、断言和未运行项 |
| 审查 | 代码/语义/原则及文档职责 | 匹配同候选审查与当前发现 |
| 交付 | 交付规划者 | 汇总当前证据、未决和接续 |

当前执行状态：等待工程、候选和时间预算绑定；已执行阶段：无。必要输入满足前不修改工程。失败回最早失效阶段；未知受理状态先查证，不能重放。需要重复时由协调 Agent 选择 Loop 并沿原任务预算接续。

相关真实案例在[原证据位置](../../examples/workflow-bookmark-tags/README.md)，其历史测试不属于本实例。
