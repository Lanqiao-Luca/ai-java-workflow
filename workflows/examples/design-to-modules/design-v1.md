# 设计候选 v1

虚构设计采用共用 BookmarkValue，标题路径仅更改标题，保留 ID 与标签。标签路径读取列表后逐项加入存储，遇到空白项返回 BAD_TAG。两个路径使用现有单进程锁；本方案不引入新存储或认证系统。

实施落点拟为值对象、标题服务、标签服务和集成测试。验收沿 R1–R5，当前没有代码或测试执行。R3 要求整次拒绝，但本候选在校验完成前修改状态，因此存在部分写入反例。
