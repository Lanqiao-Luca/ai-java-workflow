**目的**：展示采集覆盖判断的真实离线执行，保留零命中、局部覆盖和未知的不同结果。

**适用于**：学习证据采集能力线的使用者；材料完全虚构，不提供生产查询或实际来源授权证明。

# 页观察覆盖案例

[证据采集者](../../../agents/evidence-collector.md)经对应 Skill 消费采集原子和纯判定工具；[取证 Workflow](../../evidence-collection.md)组织事实与解释的交接。

输入为[八条虚构场景](scenarios.json)，执行[本地程序](run.py)：

```sh
python3 -B workflows/examples/evidence-coverage/run.py
```

程序实际读取JSON页观察并判断完整命中、有正控制的限定空结果、无正控制的未解决空结果、采样命中、预算局部、截断、拒权及未知。probe 是本例约定的可见记录，目标匹配用显式子串谓词，不能据此推定真实系统的查询能力或通道可靠性。

本判定合同只接受同一快照内唯一行ID和连续游标，重复行ID或不连续页直接拒绝；真实来源若有重叠页，须先按其真实合同形成可追溯投影，不能静默删除重复来冒充完整。

工具不请求任何来源、不验证权限、不提供连接器、批处理执行或跨重启恢复。COMPLETE_EMPTY 只表示给定快照/条件中未观察到匹配，sample 不宣称完整，失败不是有效零条。调用者必须独立核观察记录与实际来源是否相符。
