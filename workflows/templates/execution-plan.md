# Workflow 执行计划模板

执行状态：NOT_RUN。本文件是待实例化的格式，不是运行回执。

| 定义字段 | 本次填写 |
| --- | --- |
| run_id / 目标 / 需求来源 | 待填 |
| 父 Graph/Loop（没有则无）/ 总体状态位置 | 待填 |
| 当前协调 Agent / 候选及完整差异 | 待填 |
| 采用的 Workflow 合同及版本/摘要 | 待填 |
| 允许根、读写集、禁止动作 | 待填 |
| 验收与保持项 / 执行环境 / 总预算 | 待填 |

| 阶段 | 责任 Agent | 输入 | 输出与验收 | 失败返回 |
| --- | --- | --- | --- | --- |
| 需求 | 需求负责人 | 原始目标 | 确认契约 | 缺关键语义先补齐 |
| 实现 | 实现者 | 契约与候选 | 最小差异 | 返回需求或实现 |
| 验证 | 验证者 | 同候选 | 实际测试证据 | 原作者整改 |
| 审查 | 匹配的审查者 | 冻结输入 | 当前发现与回执 | 原作者定向修复 |
| 交付 | 交付规划者 | 必要证据 | 残余与接续 | 返回最早失效阶段 |

执行后另记当前阶段、实际命令与结果、证据位置、未决、在途未知、累计预算和恢复点；定义与进度分开，已有父层仅接收本轮局部结果。

由[任务协调者](../../agents/task-coordinator.md)选择 [Workflow 合同](../java-spring-development.md)，再交相应阶段 Agent 执行。纯专项任务可缩短阶段，不能删去实际必要验收。
