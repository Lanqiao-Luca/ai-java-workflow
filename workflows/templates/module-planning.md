**目的**：帮助实例化当前设计到模块的准备规划，绑定来源、写集和真实检查。

**适用于**：相应阶段已获授权且输入明确的责任 Agent；填好模板不表示执行已发生。

# 执行计划模板

采用[模块规划 Workflow](../design-to-modules.md)，由[模块规划者](../../agents/module-planner.md)承担归属与计划。

| 字段 | 本次填写 |
| --- | --- |
| run_id、目标/验收与父实例 | 待填 |
| 当前阶段、协调者与实际执行方式 | 待填 |
| 需求/设计/合同的版本与 SHA | 待填 |
| 实际工程与基线、允许读写集 | 待填 |
| 步骤输入 → 责任 → 产物/验收 → 失败恢复 | 待填 |
| 当前预算、已决/待决与必要审验 | 待填 |
| 已完成前缀、在途未知与下一消费者 | 执行后按事实记录 |

状态起始为 NOT_RUN，执行受控动作前保存真实定义与初始状态；续作不重建，候选变化只使相交证据失效。
